# JavaScript Array & String Practice

This project contains a collection of **JavaScript practice programs** focused on understanding and working with arrays, strings, loops, functions, conditions, and commonly used JavaScript methods.

The main purpose of this project is to strengthen the fundamentals of JavaScript by solving different problems using practical examples. Each question is implemented separately in JavaScript and TypeScript files.

## What I Practiced

Through this project, I practiced:

- Creating and accessing JavaScript arrays
- Using array indexing
- Adding and removing array elements
- Joining and slicing arrays
- Calculating the sum of array elements
- Finding maximum and minimum values
- Converting array elements into ASCII/character codes
- Filtering array elements using `filter()`
- Transforming array elements using `map()`
- Sorting arrays in ascending and descending order
- Reversing arrays
- Checking whether a value exists in an array
- Converting strings into arrays using `split()`
- Converting arrays into strings
- Replacing text using `replace()` / `replaceAll()`
- Finding the length of a string
- Working with string case conversion
- Using loops such as `for`
- Using `forEach()`
- Creating and using functions
- Using conditional statements
- Using the ternary operator
- Displaying JavaScript results on a webpage using DOM manipulation
